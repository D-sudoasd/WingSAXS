# JAC 论文证据与图表安排

## 核心论点

WingSAXS 将观测轨迹、参数支持、不确定度和逐帧来源一起保存，使二维 SAXS
图样变化能够被复核。当前可证明的是软件行为及所运行合成条件下的结果；
真实实验准确性、通用方法优势和三维结构反演不在已验证结论内。

期刊要求核对日期：2026-09-27。[JAC Computer Programs 作者指南](https://journals.iucr.org/j/services/notesforauthors.html)
要求交代软件目的、策略、语言、机器及输入要求、结果和科学贡献；通常应有至少
两名独立用户成功使用的证据，并为审稿人提供匿名访问。本文采用该栏目，不套用
Nature 的篇幅或创新性要求。使用 AI 辅助的情况需要如实披露并由作者复核。

## 术语与测量对象

| 固定表达 | 定义与边界 |
|---|---|
| radial peak position, q* | 径向强度剖面的峰位，物理单位下 L = 2π/q* |
| annular angular maximum | 固定 q 环上的角向极大值，q 是采样坐标 |
| Cartesian-slice maximum | 固定一个笛卡尔坐标，沿另一坐标找到的强度极大值 |
| curvature ridge | 按所记录算法的局部导数条件提取的脊线，不预设各文献实现等价 |
| apparent ellipse geometry | a、b/a、ellipse-axis angle；不等于结构倾角 |
| empirical interval | 重采样百分位区间；未经覆盖率检验不称为 calibrated confidence interval |
| candidate | 有限且可检查的受限估计，不自动排除也不自动接受 |
| warm start | 从记录的来源帧初始化；不引入时间平滑约束 |

## 参数可辨识性与后续规模

使用已有 arc 与实空间 FFT 生成器分别检验几何误差和生成模型改变。逐项扫描
轴比、倾角、可见弧长、q 窗口、噪声幅度、背景与峰重叠；组合条件应另行列出，
不可把单因素扫描称为完整交互实验。至少包含近圆环、条纹、纯噪声及混合峰族。
参数误差与边界、短弧及外推状态共同展示。

外层独立图像数由覆盖率估计所需精度决定。例如在真实覆盖概率约 0.95 时，
200 次独立试验的二项近似标准误为 sqrt(0.95×0.05/200)≈0.0154，
这是规划精度的计算，不是本项目已经取得的覆盖率。内部重采样数应另做
端点稳定性检查。不得将只有数次重复的覆盖比例称为可靠的 95% 覆盖率证明。

变化检验应明确差值 Δp 的参照与共同误差。共享 q 标定造成帧间相关性，
不能将两个帧的标准误总是按独立变量平方相加。优先用重复序列或联合扰动
同一标定、分别扰动各帧强度，直接得到差值分布。
