# 从 SAXSAnalyzer 转到 WingSAXS

WingSAXS 0.5 将二维图像中的局部测量、方位角峰分析、低 q 区域分析与片层模拟集中到同一工作台。原有蝴蝶轨迹、椭圆、全图经验强度拟合和序列分析保留原来的入口。

| SAXSAnalyzer 的二维用途 | WingSAXS 入口 |
| --- | --- |
| 人工选点、线剖面、局部方向 | 局部测量 |
| q 环内方位角峰形、宽度和残差 | 方位角峰分析 |
| 二维图像扇区的低 q 连续散射 | 低 q 区域分析 |
| 蝴蝶轨迹、双椭圆与质量诊断 | 蝴蝶分析 |
| 全图经验强度模型 | 高级强度 |
| 多帧分析、结果审核和演化 | 批处理、演化 |
| 拟合结果对应的条件片层形貌 | 实空间片层 |
| 假设片层形貌的模拟散射 | 实空间片层中的二维投影 FFT |
| 原有会话和证据包的核查 | 项目菜单中的 SAXSAnalyzer 兼容入口 |

本次不迁入独立一维数据的 Guinier、Porod、不变量或一维模型库。二维图像提取的剖面继续作为区域测量和拟合诊断使用。

## 继续处理旧图像

直接打开原始二维图像或二维数值矩阵，再选择对应的 PONI 和遮罩。CSV/TXT/DAT 必须是二维矩阵，不是两列 q–I 谱线。灰度 PNG 保留像素数值；JPEG 的有损压缩可能改变强度，定量测量应使用原始探测器文件。彩色或调色板图像不会被自动当作标量强度。

旧 Fusion 会话包含标量几何配置时，兼容工具按旧软件的平面探测器约定重建 q 坐标，并保留会话来源。它不把旧配置伪装成新的 PONI 标定。如果原始数据已移动或缺失，先核对兼容工具给出的路径与状态，再定位正确数据。

## 保留旧结果

兼容入口只读查看旧会话和证据文件，并能写出来源文件摘要及 SHA-256 记录。旧 `Ln`、`Lz`、模型结果和人工审核状态作为历史记录保留，不自动变成 WingSAXS 新测量，也不会自动认定为真实结构参数。

旧软件已归档并不改变已有结果的含义。需要重新分析时，用原始二维数据重新测量，并保留旧证据作比较；不能仅凭软件测试通过就声称两套算法对实验数据完全等价。

操作说明见[二维测量指南](image_measurements_zh.md)和[实空间片层工作台](lamellar_workbench_zh.md)。
