# 二维局部测量与方位角峰分析

这些工具以当前加载的二维探测器图像为输入，共用图像标定、坏像素遮罩和排除区域。无需先拟合蝴蝶轨迹或双椭圆，也不导入独立的一维谱线。图像中的剖面是二维测量的中间结果。

## 局部测量

打开二维图像后进入“局部测量”。选择峰位置，或在图像上选择线段端点，以检查局部强度和峰宽。局部区域的方向估计用于检查条纹方向，不自动代表层片法向或堆栈轴。

点的位置同时保留探测器像素坐标和对应的 q 坐标。只有明确的物理 q 单位才允许换算 `L = 2π/|q|`；该值是所选散射位置对应的周期，不能仅因选中了一个峰就命名为真实层片法向周期。没有 PONI 或其他明确标定时，结果仍可作为像素测量保存。

遮罩和非有限像素不参与测量。剖面中的缺口保持缺失，半高宽需要同一连续有效区域内的左右半高交点；缺少任一侧时应调整线段或报告无法确定，而不是跨过遮罩补出宽度。

## 方位角峰分析

打开“方位角峰分析”，在当前图像上选择 q 环范围，再提取方位角强度并拟合峰形。该路线用于比较取向峰位置、宽度和分裂情况，不需要双椭圆作为前置步骤。

比较不同 q 环时，应同时检查有效像素数、角度覆盖和拟合残差。遮挡区域和没有像素的角度箱不是零强度观测。峰的角向宽度与径向峰宽是不同的测量量，不能相互换算。

## 与原有工作流的关系

蝴蝶轨迹、双椭圆、全图经验强度拟合和批处理沿用原有入口。局部测量和方位角峰拟合用于独立检查图像，不向这些拟合流程注入人工补点，也不修改原始图像。

更换图像、标定或排除区域后，应重新测量；不能把上一帧结果作为新一帧的观测。导出时保留所选位置、q 单位、原始剖面及测量或拟合诊断。

## 低 q 区域分析

“低 q 区域分析”从当前二维图像的指定 q 范围和方位扇区提取强度，分别检查幂律和 Ornstein–Zernike 经验模型。扇区、q 范围、有效像素和残差应与参数一同检查。该功能只接收二维图像，不导入独立的一维数据文件。

幂律指数和 Ornstein–Zernike 相关长度是所选窗口与模型下的估计。有限拟合值与充分的参数约束不是同一件事；缺少低 q 转折或有效范围过窄时，不应把相关长度解释为已测得的片层周期。

## 实空间模拟

“实空间片层”沿用拟合结果中的来源信息建立条件形貌。层数、片层尺寸、位置分散及层间距分散等参数是显式结构假设，不能由一张二维 SAXS 图样唯一确定。

页面提供单堆栈和多堆栈预览。没有可用拟合结果时，可用相对尺度的手动示意检查片层组织，并显式设置第二组法向角度；这两组手动方向不会被记录成实测分支。有拟合结果时，展示预设保留参数来源。序列中缺失的拟合分支仍保留空位，避免用另一分支填充后改变组织显示。

投影密度的二维 FFT 预览用于检查这些假设如何改变模拟散射。它计算有限二维密度场的傅里叶强度，使用 `q = 2πf`，与全图经验强度拟合分别保存。它不是绝对强度计算，也不包含完整三维取向分布、仪器分辨率或多重散射；图像上的有限视场和像素分辨率会影响模拟结果。
